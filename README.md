# cppPractice

Welcome! This repository is my personal sandbox for mastering C++ from scratch. Instead of just writing generic "Hello World" scripts, I’m building foundational mathematical data structures and libraries. 

My goal here is to bridge the gap between high-level mathematical concepts and low-level computational efficiency—focusing on manual memory management, pointers, and performance optimization.

## 📁 What's Inside?

*   **`DynamicMatrixLibrary.cpp`**
    *   *The Why:* Matrix operations are the backbone of combinatorial optimization and machine learning algorithms. 
    *   *The Focus:* I built this to get my hands dirty with dynamic memory allocation, multi-dimensional array manipulation, and pointers. It handles core matrix transformations without relying on heavy external overhead.
*   **`PolynomialLibrary.cpp`**
    *   *The Why:* Representing algebraic objects cleanly in a strictly-typed language requires solid object-oriented design.
    *   *The Focus:* This library maps polynomial properties (like coefficients, degrees, and arithmetic operations) into structured C++ code. 
*   **`references.cpp` & `student.cpp`**
    *   Syntactic practice files covering core C++ mechanics like pass-by-reference efficiency and standard object paradigms.

## 🛠️ Tech Stack & Concepts Covered
*   **Language:** C++
*   **Concepts:** Dynamic memory allocation, Pointer arithmetic, Object-Oriented Programming (OOP), Matrix transformations.
